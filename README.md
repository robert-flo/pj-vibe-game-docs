# Super Bukele 64 — Documentación Académica de Vibecoding Guiado

Sitio de documentación construido con **Jekyll (`jekyll-vitepress-theme`)** para la entrega individual de **Vibecoding con IA (Semana 2)**. Registra de forma cronológica el proceso completo de diseño, prompts, arquitectura, depuración de bugs con evidencia visual y reflexión académica del proyecto.

- **Sitio de Documentación publicado**: https://robert-flo.github.io/pj-vibe-game-docs/
- **Juego 3D en vivo**: https://robert-flo.github.io/pj-vibe-game/
- **Repositorio del Juego**: https://github.com/robert-flo/pj-vibe-game

## Estructura de Contenidos (`_docs/`)
1. `introduccion.md` — Contexto académico, evolución del alcance y justificación tecnológica.
2. `arquitectura.md` — Máquina de 7 estados, pipelines Python/Blender, raycasting 3D y audio híbrido.
3. `prompts.md` — Registro cronológico completo de los **19 prompts** enviados y su análisis técnico.
4. `iteracion.md` — Bitácora detallada de las **18 iteraciones** y galería visual comparativa del proceso.
5. `validacion.md` — Metodología de pruebas WebGL y **9 casos reales de bugs** diagnosticados y corregidos.
6. `reflexion.md` — Análisis crítico de aprendizaje, ventajas/límites del vibecoding y dominio del código.
7. `demo.md` — Juego incrustado en vivo y guía completa de escenas y controles.
